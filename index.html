Titulos

Os titulos de uma pagina podem variar entre h1 ate h6,
a sequencia desses titulos deve ser respeitada Pois
representa a importancia da informação dentro dos
motores de busca do navegador. Para entender melhor
cada navegador teu seu proprio motor de busca, que
faz o trabalho de encontrar a informção que você
pesquisou, ele vai ler as informações mais importantes
da pagina para te entregar os sites corretos. Então
se no código da pagina a informção mais importante não
estiver escrita no h1 o motor de busca do navegador
não vai encontrar a resposta para a pesquisa dentro da
pagina.

Tags

As tags são a base código em si, elas determinam a
função de cada coisa como a tag "h1" dis para o
navegador que o que estiver ali no meio é um titulo,
a tag "p" dis que aquilo é um paragrafo e assim por
diante cada tag determina uma função para o que você
digitou entre ela. As tags tem um formato padrão que seria, <tag>
para abertura e </tag> para fechamento, ainda sim tem
algumas tags que não necessitam de fechamento como a tag
"imagens" ou a tag "br" que é para quebra de linha.
As tags podem ser colocadas uma dentro da outra para
aplicar formatações combinadas, como a tag "strong" que
pode ser usada dentro da tag "p" para deixar uma palvra
em negrito dentro de um paragrafo,
que tambem pode ser usada a tag "b" que faz a mesma função
de deixar a palavra em negrito, temos a tag "i" para italico

Listas

existem 2 tipos de listas no html, as listas ordenadas que
são aquelas onde a ordem dos itens importa, e as não ordenadas
que é quando a ordem dos itens não é importante. pras ordenadas
usamos a tag 'ol' e pras não ordenadas usamos a tag 'ul' ambas
seguidas da tag 'li' usada para determinar os intens da lista.

Lista ordenada

  1. Item 1
  2. Item 2
  3. Item 3
  4. Item 4

Não ordenada

  • Item 1
  • Item 2
  • Item 3
  • Item 4

Links

os links são criados com a tag 'a' seguida do atributo 'href' onde
colocamos o endereço do site para onde queremos ser redirecionados,
o texto que fica entre a abertura e o fechamento da tag 'a' é o texto
que vai aparecer para o usuário clicar, o atributo 'title' é usado para
colocar um texto de descrição para o link, e o atributo 'target' é usado
para abrir o link em uma nova aba, usamos o valor '_blank' no atributo 'target',
para abrir no mesmo site podemos simplesmente não usar o atributo 'target'.

Ancora

as ancora são usadas para criar um link dentro da mesma pagina,
como uma forma de atalho para algum lugar da propria pagina, para isso
usamos a tag 'a' seguida do atributo 'href' com o simbolo '#' e o id da ancora.
o id da ancora é criado usando o atributo 'id' em alguma tag, como por
exemplo: <h2 id="ancora1">Ancora 1</h2> ,criado esse id
você pode criar o link da ancora que ficará assim: <a href="#ancora1">ancora 1</a>
essa ancora vai levar o usuário para o local da pagina onde a tag com o id
"ancora1" estiver localizada.

Imagens

as imagens são inseridas usando a tag 'img' seguida do atributo 'src' onde
colocamos o endereço da imagem, usamos width e height para definir o tamanho da imagem,
o atributo 'alt' é usado para colocar um texto alternativo para a imagem, caso ela
não seja carregada ou para leitores de tela, o atributo 'title' é usado para colocar,
um texto de descrição para a imagem. tambem é possível usar a tag 'a' para transformar
a imagem em um link, para isso basta colocar a tag 'img' dentro da tag 'a' e colocar o
endereço do link no atributo 'href' da tag 'a'.,
exemplo: <a href="https://google.com" title="Google" target="blank">
<img src="imagens/images.jfif" width="250" height="100" alt="imagem programador">

Audio

o audio é inserido usando a tag 'audio' seguida do atributo 'src' onde
colocamos o endereço do arquivo de audio, o atributo 'controls' é usado para
mostrar os controles de play, pause e volume para o usuário, o atributo 'autoplay'
é usado para fazer o audio tocar automaticamente quando a pagina for carregada,
e o atributo 'loop' é usado para fazer o audio tocar em loop, ou seja, repetir
automaticamente quando chegar no final.
