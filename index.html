Titulos

Os titulos de uma pagina podem variar entre h1 ate h6,
a sequencia desses titulos deve ser respeitada Pois
representa a importancia da informação dentro dos
motores de busca do navegador. Para entender melhor
cada navegador teu seu proprio motor de busca, que
faz o trabalho de encontrar a informção que você
pesquisou, ele vai ler as informações mais importantes
da pagina para te entregar os sites corretos. Então
se no código da pagina a informção mais importante não
estiver escrita no h1 o motor de busca do navegador
não vai encontrar a resposta para a pesquisa dentro da
pagina.

Tags

As tags são a base código em si, elas determinam a
função de cada coisa como a tag "h1" dis para o
navegador que o que estiver ali no meio é um titulo,
a tag "p" dis que aquilo é um paragrafo e assim por
diante cada tag determina uma função para o que você
digitou entre ela. As tags tem um formato padrão que seria, < tag >
para abertura e < / tag > para fechamento, ainda sim tem
algumas tags que não necessitam de fechamento como a tag
"imagens" ou a tag "br" que é para quebra de linha.
As tags podem ser colocadas uma dentro da outra para
aplicar formatações combinadas, como a tag "strong" que
pode ser usada dentro da tag "p" para deixar uma palvra
em negrito dentro de um paragrafo,
que tambem pode ser usada a tag "b" que faz a mesma função
de deixar a palavra em negrito, temos a tag "i" para italico

Listas

existem 2 tipos de listas no html, as listas ordenadas que
são aquelas onde a ordem dos itens importa, e as não ordenadas
que é quando a ordem dos itens não é importante. pras ordenadas
usamos a tag 'ol' e pras não ordenadas usamos a tag 'ul' ambas
seguidas da tag 'li' usada para determinar os intens da lista.

Lista ordenada

  1. Item 1
  2. Item 2
  3. Item 3
  4. Item 4

não ordenada

  • Item 1
  • Item 2
  • Item 3
